# Wild Horizons

A 3D park-building game for desktop and mobile browsers, made with three.js. You shape a wild landscape, protect its natural wonders and work your way up to **National Park** status.

## Play locally

```bash
npm install
npm run dev      # dev server; it is also reachable from a phone on the same network
npm run build    # writes a static site to dist/ that can be hosted anywhere
```

## Android and iOS apps

The apps wrap the same web game with [Capacitor](https://capacitorjs.com); the website is unchanged.

- `capacitor.config.json` – app ID (`com.mearkus.wildhorizons`), name, splash and status bar
- `android/`, `ios/` – the native projects (generated by Capacitor, safe to edit)
- `assets/` – source images for the app icon and splash screen. After changing them, run
  `npm run cap:assets`
- `src/native.js` – native extras: saves backed up to device storage (iOS can clear web
  storage when space is low), haptics, the Android back button, pausing when the app is
  backgrounded, status bar and splash screen. All no-ops on the website.

**Installing a build:** every push to `main` updates the
[Latest build](../../releases/tag/latest-build) pre-release:
- `WildHorizons-debug.apk` – open it on an Android phone to install (allow "install unknown apps").
- `WildHorizons-simulator.zip` – an unsigned build for the iOS Simulator. Unzip and drag `App.app`
  onto the Simulator. Real iPhones need a signed TestFlight build.

**Developing:** `npm run cap:sync` builds the game and copies it into both apps, then
`npx cap open android` (Android Studio) or `npx cap open ios` (Xcode).

## How it works

- **Landscapes**, each based on real parks: Geyser Plateau (Yellowstone), Granite Valley (Yosemite & Sequoia), Red Rock Canyon (Arches, Bryce & Zion), Rainforest Coast (Olympic & Acadia) and Alpine Lakes (Glacier & Rainier).
- **Scores:** Beauty, Uniqueness, Ecology and Enjoyment, plus funds and annual visitors.
- **Designations:** Wild Land, then State Park, then National Monument, then National Park. Bonus honors are Wilderness Area, Dark Sky Park and World Heritage Site.
- **Tools:** trails, roads, forests, meadows, ponds, wildlife herds, the landscape's signature natural wonders, and facilities (visitor center, campground, lodge, overlook, ranger lookout).

Controls: drag to orbit, pinch or scroll to zoom, and use two fingers or right-drag to pan. Paint tools are drawn by dragging.
