# Wild Horizons

A 3D park-building game for desktop and mobile browsers, made with three.js. You shape a wild landscape, protect its natural wonders and work your way up to **National Park** status.

## Play locally

```bash
npm install
npm run dev      # dev server; it is also reachable from a phone on the same network
npm run build    # writes a static site to dist/ that can be hosted anywhere
```

## How it works

- **Landscapes**, each based on real parks: Geyser Plateau (Yellowstone), Granite Valley (Yosemite & Sequoia), Red Rock Canyon (Arches, Bryce & Zion), Rainforest Coast (Olympic & Acadia) and Alpine Lakes (Glacier & Rainier).
- **Scores:** Beauty, Uniqueness, Ecology and Enjoyment, plus funds and annual visitors.
- **Designations:** Wild Land, then State Park, then National Monument, then National Park. Bonus honors are Wilderness Area, Dark Sky Park and World Heritage Site.
- **Tools:** trails, roads, forests, meadows, ponds, wildlife herds, the landscape's signature natural wonders, and facilities (visitor center, campground, lodge, overlook, ranger lookout).

Controls: drag to orbit, pinch or scroll to zoom, and use two fingers or right-drag to pan. Paint tools are drawn by dragging.
